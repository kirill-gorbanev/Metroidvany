## 0. Как устроен шаг (без этого остальное не читается)

| Что | Где | Суть |
|---|---|---|
| Цикл | P:1058 `Update` | Кадр делится на шаги логики ≤ `maxStepDt` 0.02 с (догон не больше `maxCatchUp` 0.25 с). В каждом шаге: платформы `ProtoMover.Step(dt)` → `Tick(dt)`. `FixedUpdate` не используется нигде. |
| Tick | IP:63 | `TickLogic(dt)` (вся логика «из позиций») → `ArmDrive(dt)` (раз за шаг) → n равных шагов физики ≈ `physicsDt` 0.005 (n = 1…40) → `ArmReadback()`. |
| Физика | IP:87 | `Physics.simulationMode = Script` — **герой сам шагает всю физику сцены** (`Physics.Simulate`). В `OnDisable` возвращает `FixedUpdate`. `TimeManager`: Fixed Timestep 0.02. |
| Порядок TickLogic | P:1092 | `RightingUndo` → `Carry` (платформы) → `PushStep` → ввод → `FallStep` (полёт / оглушение — вместо остального) → ветка Free (`DragFreeStep` → зацеп → пол) или Grip (`Gesture` → `HandSlipStep` → поворот → ход по линии) → `SlopeStep` → `SpinStep` → `ClimbDecay` (`ArmReachStep`, `HangHandCreep`, `MantleStep`) → `Place` (высоты, локоть) → `BackSlotStep` → `StateStep` → `ClimbVisuals` → `Draw`. |
| Мир | P:477, 489, 534; Cl:86 | Логика ходит **не по коллайдерам**: стены = `Rect` по `Renderer.bounds` детей `obstaclesRoot` (+ верх `obstacleTop`), рельеф = треугольники сеток `surfaceRoot` (свой `RayTri`), пол = плоскость y = 0, платформы = сетки `ProtoMover` в локальных координатах. |
| Коллайдеры | IP:21 `EnsureItemWorld` | В сценах **нет ни одного коллайдера** (в `HeroArena.unity` и `HeroArmCourse.unity` 0 `BoxCollider` / `MeshCollider`). Они создаются в рантайме: `MeshCollider` на каждую сетку под `surfaceRoot` и `obstaclesRoot` (включая выключенные зоны и сетки платформ) + пол-бокс 4000 × 1 × 4000 с верхом y = 0. Декор (земля, поручни, камни, подписи) коллайдеров не имеет. |

## 4. Ввод и жест (наследуется один в один)

### 4.1 Сбор ввода

- `Update` (P:1063): `pos` = `Mouse.position` (px, начало — левый низ), `delta` **суммируется** между шагами логики, `pressed` = ЛКМ зажата, `down` — «нажата в этом кадре» (липкий до шага), `orbit` = ПКМ зажата (`ProtoOrbitCamera.Orbiting`).
- Весь накопленный `delta` тратится **первым** шагом логики кадра (P:1107). Единица — сырые px мыши (New Input System `Mouse.delta`).
- Внешний водитель: `driver` (`Func<InputFrame>`) заменяет мышь — так работают бот и стенды. `InputFrame { Vector2 pos, delta; bool pressed, down, orbit; }` (P:1028).
- Курсор заперт в окне (`CursorLockMode.Confined`), пока ЛКМ зажата в хвате или с предметом.
- Клавиши: `H` — подсказки; `1…9`, `0` — зоны (`ProtoZones`).

### 4.2 Курсор → цель свободной кисти (P:1118–1143)

1. `px = pos + (0, inputShift · Screen.height)` (сдвиг = 0).
2. `FloorPoint(px)`: луч камеры → ближайшее из: треугольники рельефа, платформы, плоскость y = 0, верх стены не выше `BodyLevel + climbUp`. Попали выше `BodyLevel + maxStep + 0.05` в перекрытие, а под ним есть свой пол (ниже на > 0.1) — луч продолжается (до 4 раз). Берётся только XZ точки.
3. `MirrorBehind`: если `Dot(p − тело, лицо) < 0` → `v = (тело − (p − тело)) − плечо`; если `Dot(v, лицо) ≤ 0.01` → `v = лицо`; цель = `плечо + norm(v) · 0.22`.
4. `Reach`: вектор от плеча, длина ≤ `L` (0.62, **по XZ**), угол от лица зажат в [−50°, +70°] (плюс — вправо, `SignedAngle(Face, v, up)`).
5. `HandAtLedge`: марш от плеча шагами 2 см до первой преграды; если отрезок режет своё тело — направление доворачивается к лицу (12 бисекций), длина та же; результат не ближе 5 см к плечу; затем `HandOutOfBody`.
6. `hand = Lerp(hand, цель, 1 − exp(−18·dt))`; затем `FreeHandAroundBody` (поворот вокруг плеча шагами 10° до «не режет тело») и `HandOutOfBody`.
7. До шага 2 проверяются: предмет под курсором (кисть идёт к точке на нём), потом зацеп `FindHold` (кисть идёт к его точке).
8. Высота кисти — отдельно, в `Place`: `handY` догоняет поверхность под кистью (8 1/с, не быстрее 1.2 м/с), никогда не ниже поверхности.

### 4.3 Нажатие ЛКМ

Приоритет: предмет (`BeginDrag`) → зацеп (`BeginGripHold`) → пол (`BeginGrip(HandAtLedge(Reach(Mirror(c))))`). Кисть встаёт в точку хвата **сразу** (не догоняет). Линия хода: `dir = norm(кисть − плечо)` по XZ; `farEnd = кисть − dir · ArmLenMax` (рука вытянута или упёрлась в своё тело), `nearEnd = кисть − dir · min(0.18, текущее расстояние)`; `t` = проекция плеча, 0 — вытянута, 1 — согнута.

### 4.4 Жест при зажатой ЛКМ (P:1368 `Gesture(md)`, `md` — px за шаг)

```
push  = −md.y                      // мышь вниз («на себя») — плюс
axis  = Screen(nearEnd) − Screen(farEnd);  axisLen = |axis| (px);  если axisLen < 1 — выход
travel = norm(nearEnd − farEnd) · sign(push)
fwd   = Dot(travel, лицо)                         // +1 лицом, −1 спиной
k     = Lerp(0.45, 1, (fwd + 1) / 2) · moveK
phi   = SignedAngle(лицо, кисть − точка_линии(t), up)      // плюс — кисть справа
moveK = 1 − clamp01((phi − 70) / (100 − 70))  при phi ≥ 0;  1 − clamp01((−phi − 50) / (100 − 50))  при phi < 0
tTarget = clamp01(tTarget + push · k / axisLen)
```

- Смысл: 1 px мыши по вертикали = столько метров, сколько 1 px занимает **на проекции линии хода на экран** (`mpp = длина_линии / axisLen`), умножить на `k`. Берётся только вертикаль мыши — независимо от того, как линия повёрнута на экране; но масштаб зависит от проекции (линия «в торец» к камере → `axisLen` мал → чувствительность растёт).
- Тело: `t = Lerp(t, tTarget, 1 − exp(−14·dt))`, место = `Lerp(farEnd, nearEnd, t) − SideOff`.
- Поворот:
```
r   = max(0.12, |кисть − точка_линии(t)|)
deg = −md.x · mpp / r · Rad2Deg · turnGain(1) · turnSensitivity(0.4)
если ReverseSteering: deg = −deg
pendingTurn = clamp(pendingTurn + deg, phi − 90, phi + 90)
каждый шаг: step = pendingTurn · (1 − exp(−10·dt));  rotation = AngleAxis(step, up) · rotation;  pendingTurn −= step
```
  Смысл: дуга кисти вокруг тела (в метрах) = боковой ход мыши в метрах экрана × 0.4.
  **Знак — внимание:** по коду мышь вправо (`md.x > 0`) даёт отрицательный угол, то есть рыскание тела против часовой стрелки сверху (в Unity `AngleAxis(+, up)` ведёт +Z к +X). В комментариях, у бота и в документе знаний это названо «мышь вправо = поворот вправо» (на экране при камере за спиной точка хвата уходит вправо, вслед за мышью). Знак зафиксирован автором («не менять») — переносить **по записи ввода со старого контроллера**, а не по словам.
- Передача: `reverseGear` меняется, только если `|push| ≥ 0.5 px`, `|push| > |md.x|` и `fwd < −0.5` (включить) / `fwd > 0.5` (выключить). `ReverseSteering = reverseSteer && reverseGear && !mirrorGrip`.
- До езды жест может забрать: «отпустить» (R47), сход спиной (E19), срыв спиной (E23), «рука выводит тело» (доворот `−push · 0.3 °/px`), подъём у кромки (`push · Px1080 · 0.0012 м`).
- `Px1080 = 1080 / Screen.height` — к этой единице приведены пороги «отпустить», срыв, подъём, воздух при переносе, наклон камеры. Езда и поворот к 1080 **не приводятся** — они и так в доле экрана через `axisLen`.

### 4.5 Ввод при переносе предмета

- Зона пола: точка курсора = первая поверхность по лучу (физика, `CarrySurfaceCollider`), но не дальше плоскости высоты низа предмета; `r = Reach(p)`; над телом в досягаемости — сама точка. `dragTarget = Lerp(dragTarget, HandAtLedge(r + смещение, carry), 1 − exp(−18·dt))`. Высота низа предмета догоняет верх поверхности под кистью (+0.005) с той же постоянной.
- Воздух (курсор выше края зоны на > 30 px@1080 на той же высоте): `m = right_камеры_по_полу · (dx · k) + up · (dy · k)`, `k = Px1080 · 0.002 м/px`; цель зажата в сферу `L · 0.999` вокруг плеча (3D), в сектор (или над телом), в `HandAtLedge(carry)`; кисть догоняет с `handFollow`.
- Выход из воздуха — курсор зашёл в зону на 3 см вглубь.

### 4.6 Камера

- Жёсткая орбита за спиной: `rot = Euler(pitch, yaw, 0)`, позиция = `focus − rot·forward · distance`. `yaw` получает **мгновенно** приращение рыскания тела (`DeltaAngle`) — сглаживания поворота нет. `focus = Lerp(focus, тело + up · 0.15, 1 − exp(−6·dt))`, `dt` — `unscaledDeltaTime`.
- ПКМ + мышь по вертикали: `pitch −= dy · Px1080 · 0.2`, 10…85°. По горизонтали ПКМ не крутит (`yawSpeed` не используется). Колесо: `distance ×= 1 ∓ 0.1`, 0.8…8.
- Пока ПКМ зажата — рука и жест замирают.
- `target` камеры = `bodyCube`; при физическом падении кубик кувыркается, камера берёт только его рыскание (`eulerAngles.y`) — на кувырке возможны скачки рыскания.
- В `ManualTick` камера шагается симуляцией (`Cam.Step(Dt)`), мышь не читает.
- Камера нужна вводу напрямую: `ScreenPointToRay`, `WorldToScreenPoint` (линия хода, радиусы автозахвата в px, порог «воздух»), `cam.transform.right / forward` (перенос в воздухе).
