# Сетка локации — формат карт

Локация собирается в Unity из блоков набора (Quaternius Medieval Village + Fantasy Props) на сетке.
Первый вариант пишется текстом: `level/<loc>/site.txt`, `L<k>.txt` (по файлу на уровень) и `dressing.txt` (предметы).
Компилятор `python -I level/gridc.py <loc>` проверяет карты и пишет `level/<loc>/build.json`.
Unity собирает сцену меню **Fortress → Grid → Build Scene: <loc>** (сцена `Assets/Scenes/Grid_<loc>.unity`).
Дальше автор правит сцену в Unity руками. Пересборка из карт затрёт ручные правки сцены, но не правки префабов.

## Размеры
- Клетка 2×2 м, этаж 3 м. Уровень `L<k>` — пол на высоте `3·k` м: L-1 подвал (−3 м), L0 земля (0), L1 (+3), L2 (+6)…
- Стена стоит на ребре клетки, толщина 0.4 м, или 0.8 м, если камень нужен с обеих сторон. Чистая ширина комнаты в 1 клетку — 1.6 м.
  Кровать (1.9×2.4) в такую не влезет: жилым комнатам нужно минимум 2×2 клетки.
- Потолок 2.78 м. Комната в 2 этажа — на верхнем уровне клетки пустые `' '`, а стены продолжены.
- Деревянная лестница — 2 клетки разбега на 1 этаж; каменная уличная — 3 клетки. Деревянная снаружи над землёй (леса) встаёт на столбы, вход на неё может быть с настила `=`.
- Большую карту удобнее писать генератором (пример — `level/fortress/_gen.py`: комнаты прямоугольниками, стены по правилам, проёмы списком, начинка в `_dress.py`).

## site.txt
```
name Крепость-тюрьма
size 60 48          # ширина и высота в клетках (одинаковые для всех уровней)
origin -60 -48      # мировые X,Z юго-западного угла клетки (0,0)
spawn L-1 12,30     # старт игрока: уровень и клетка i,j
point зал L0 20,24  # точки быстрого перехода (клавиши 2..9 в бродилке)
plain_solid 1       # наружные грани массива и стенки рва — гладкая кладка без деревянного пояса
exit Ворота L0 24,5 S   # ребро «выхода из стен»: последнее пересечённое — метка побега (имя может повторяться)
finish border       # финиш — внешний берег по краю карты (Unity ставит триггер; побег засчитан с меткой выхода)
```
Клетка `i,j`: `i` растёт на восток (вправо на карте), `j` на север (вверх). Строка карты сверху — самый северный ряд.

## L<k>.txt
Сначала описания, потом строка `map` и карта.
```
room a name="Камеры" floor=stone walls=stone ceiling=stone
room k name="Кухня"  floor=wood  walls=plaster ceiling=wood
roof  Roof_RoundTiles_6x8 at=12,20 rot=90 len=8.7   # крыша над этим уровнем; at — точка сетки (в клетках, можно .5);
                                                     # len — длина по коньку в метрах: длина дома + 0.7 (свес над фронтонами)
gable Roof_Front_Brick6   at=9,20  rot=90    # фронтон (треугольник стены под скатом)
map
+-+-+-+
|a a|.|
+-+D+ +
```
- `floor`: stone | brick | redbrick | wood | woodlight.
- `walls`: stone (камень изнутри) | plaster (штукатурка изнутри — жилое, уютнее).
- `ceiling`: каким будет потолок у этой комнаты, то есть низ пола уровня выше: wood | woodlight | stone | brick.
- `sky=1` — комната без крыши, двор-колодец.
- `narrow=1` — разрешить ширину в одну клетку (лаз, шахта). Без этого каждая клетка комнаты должна входить в квадрат 2×2 той же комнаты (правило A7: «не узко»).
- `plain=1` — укреплённая комната (башня, донжон, галерея): наружная половина стены — кладка без деревянного пояса, балка над проёмом — каменная перемычка (B11).
- `nav=player` — ход только для игрока (лаз, сток): стража сюда не ходит, ею игрок рвёт погоню.
- `tall=1` — двухсветная комната (зал, церковь): пустые клетки `' '` прямо над ней на уровне выше — её второй свет.
  Стены и окна там — её (объявите ту же букву комнаты и на уровне выше: на ней галерея, перила `r` к пустоте ставятся сами),
  потолок — на два этажа выше, карниз на полвысоты не ставится. Люстра — только в такой комнате (низ ≥ 2.2 м, цепь до потолка).
- `roof ... s=1.3 sy=1.15` — равномерный масштаб крыши (шатёр башни) и отдельно её высота.
- `bolt i,j <N|E|S|W> side=<N|E|S|W>` — засов на ребре: открыть можно только со стороны `side`, потом проход обычный.
  `bolt i,j U side=U` — засов люка стремянки (i,j на этом уровне) сверху: снизу не открыть, пока не отперли сверху.

### Карта
Удвоенная сетка: на `W` клеток приходится `2W+1` символов в строке, на `H` клеток — `2H+1` строк.
Нечётные позиции в нечётных строках — клетки. Между ними — рёбра: горизонтальные в чётных строках, вертикальные в чётных колонках.
Угловые позиции (чётная строка и чётная колонка) игнорируются: пиши `+` или пробел.

**Клетки**
| символ | что это |
|---|---|
| `a`–`z` | комната (пол, потолок, замкнутые стены); буква `v` занята стрелкой лестницы |
| `.` | трава (земля на этом уровне) |
| `:` | мощёная площадка снаружи: двор, дорожка, боевой ход по стене, плоская крыша |
| `,` | грядка/почва |
| `=` | деревянный настил (мост, мостки, балкон) — единственный пол, которому разрешено висеть: ставит опоры вниз |
| `_` | мост над водой: настил вровень с полом уровня, под ним вода и дно рва, сваи до дна. Края к воде — перила `r` |
| `#` | сплошной каменный массив (тело стены, земля под двором, скала). Грани наружу облицовываются кладкой, сверху — пол уровня выше |
| `~` | вода: поверхность на 1 м ниже пола уровня, дно на 3 м ниже. Берега — каменная подпорная стенка |
| `L` | вода с лестницей-стремянкой на берег (у каждого водоёма нужна хотя бы одна) |
| `^ v > <` | лестница, стрелка — куда подниматься. 2 одинаковые клетки подряд — деревянная, 3 — каменная. Перед первой клеткой — проходимый вход, после последней на уровне выше — проходимый выход. Над всеми клетками лестницы на уровне выше — пустота `' '` |
| `H` | стремянка на уровень выше. Над ней на уровне выше пустота `' '` (люк). С одной стороны у `H` стена/массив, и с той же стороны наверху открытый выход на пол |
| `H` над `H` | шахта со скобами (дымоход, колодезный ствол): клетки шахты окружены глухими стенами, выход только у верхней `H` |
| `O` | колодец: каменный оголовок над дырой; внизу на уровне ниже вода `~`/`L` или пол |
| `' '` | пусто: воздух, второй свет зала, проём лестницы или люка |

**Рёбра**
| символ | что это |
|---|---|
| `' '` | нет стены — только между клетками одного помещения или улицы |
| `\|` `-` | глухая стена |
| `D` | дверь: каменная стена с проёмом и деревянной створкой (E — открыть) |
| `A` | арка: проём без створки |
| `W` | окно со стеклом, рамой и ставнями снаружи |
| `w` | узкое окно с решёткой (подвал, тюрьма) |
| `B` | решётка во всю высоту (фасад камеры) |
| `X` | решётка, которую можно выбить (E) |
| `G` | ворота-калитка: каменная арка с коробкой, подъёмная решётка в толще стены (E) — только для людей |
| `V` | широкие ворота для подвод и скота: подряд идущие `V` на одной линии — один проём. Просвет 4 м (у пары рёбер 3.7 м), высота 2.8 м, каменные косяки и перемычка, створки распахнуты внутрь, подъёмная решётка поднята (E — опустить) |
| `Y` | широкий проезд (склад, внутренняя арка ворот): как `V`, без решётки; стража по нему ходит |
| `p` | парапет: каменный бортик 1 м (боевой ход, край крыши) |
| `r` | перила (край проёма лестницы или галереи) |
| `f` | деревянный забор (огород, загон) |
| `!` | открытый край, прыжок вниз задуман |

## Что проверяет компилятор
Ошибка не даёт собрать чистую сцену. Цель — 0 ошибок. Номер правила в сообщении — из `level/ASSEMBLY_RULES.md`.
- Комната замкнута: на любой её границе стоит стена, проём или решётка.
- Дверь, арка и ворота ведут в проходимые клетки с обеих сторон. В массив или пустоту — нельзя (выход в никуда).
- Окно не упирается в массив.
- Пол не висит: под ним массив `#` или помещение. Висеть может только настил `=`.
- Над комнатой есть пол, массив или крыша. Иначе нужен `sky=1`.
- Лестницы: правильная длина, вход внизу, выход наверху, проём над ними.
- Края проёмов и обрывы огорожены (`r`, `p`, стена) или помечены `!`.
- Связность: от старта достижима каждая проходимая клетка. Учитываются двери, лестницы, стремянки и вода.
- Предметы: стоят на полу, не лезут в стены, не наезжают друг на друга, не перекрывают двери и лестницы, на полке помещаются.

## guards.txt — гарнизон и обходы
```
guard G1 role=jailer L0 18,29 face=N walk=1.5 run=5.8 mask=walk,door,stair
route G1 loop                       # loop — петля, back — туда и обратно
wp G1 L0 18,29 wait=4 look=E do=take:kitchen_bowls   # точка обхода: стоянка, взгляд, действие с предметом по id
wp G1 L-1 14,29 wait=8 look=S sit=jail_post          # sit — сидит на стуле (id из dressing)
wp G6 L1 13,28 wait=4 every=2 do=take:arrows         # every=2 — точка только в каждом втором обходе
sleep G2 bed=inf_bed1 wake=12 on_wake=shout          # спящий на своей кровати
```
Пишет `fortress/_gen.py` из `_guards.py` (координаты замысла). Компилятор проверяет (G5): страж и точки на полу,
соседние точки связаны путём стражи (пол, лестницы, двери `D`, арки `A`; без воды, стремянок, люков, `!`, решёток,
трещин `C`, ворот `G`, засовов и комнат `nav=player`), `sit/do/bed` ссылаются на id предметов; печатает длину и цикл обхода.
Unity: капсулы-заглушки с NavMeshAgent и `GuardPatrol` (двери на пути открывают и закрывают за собой).

## dressing.txt — предметы
```
# [id:]Модель  L<k>  i,j  якорь  [ключ=значение ...]
t1:Table_Large  L0 20,24 N
Cauldron        L0 20,24 on:t1 dx=-0.5
Torch_Metal     L0 21,24 E h=1.9
Barrel          L0 19,23 SW
Chandelier      L1 20,24 c h=2.7
```
- Якорь `c` — центр клетки. `N`/`E`/`S`/`W` — спиной к этой стене (предмет смотрит в комнату).
  `NE`/`NW`/`SE`/`SW` — в угол: спиной к первой стене, боком ко второй. `on:<id>` — сверху на предмет с этим id; он должен быть описан выше.
- `dx`, `dz` — сдвиг в метрах по мировым осям (восток, север). `rot` — доворот в градусах. `s` — масштаб.
- `h` — высота подвеса для настенных предметов: факел, фонарь, полка, щит, знамя, плющ. Подвесные (люстра) — с якорем `c`.
- `glow=r,g,b` (0..1) — любой предмет светится этим цветом (`power=`, `range=`): руны круга, угли.
- Светильники (Torch_Metal, Lantern_Wall, CandleStick*, Candle_*, Chandelier) сами ставят источник света: `power=`, `range=`, `shadows=1`, `light=none`.
- Список моделей и их габариты (в метрах) — `level/catalog.json`. Пак `Extra` — деревья, кусты, трава, камни, мешки, еда, камин (FantasyEnvironments). Деревья 9–19 м высотой — только снаружи.
- Предмет не может быть выше потолка (2.78 м над полом), если над клеткой есть пол.

## Ограничения бродилки
- Ползать нельзя: туннели и лазы — обычные проходы в 1 клетку (1.6 м чистыми, 2.78 м высоты).
- Падение без урона: прыжок в шахту или ров — законный короткий путь, если внизу вода или пол.
- Прыжок 1.1 м, шаг 0.45 м. Из воды на берег — только по `L`.
