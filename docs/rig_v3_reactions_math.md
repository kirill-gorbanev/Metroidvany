# Риг v3 — «анимация главная, физика — отклик»: математика

Черновик архитектуры (15.11.2026). Версия 2 (физическое тело всегда видно) сохранена:
`D:\Metroidvany\versions\rig_v2_okruzhenie_2026-11-15.zip`.

## Почему v2 «деревянный»

Видимое тело — 13 твёрдых тел на пружинах, которые тянутся за невидимой анимацией.
Пружины запаздывают и сглаживают; управление идёт через два фильтра (контроллер ног → пружины).
В Euphoria/PuppetMaster наоборот: **видна анимация**, физика добавляет отклик в момент удара и отдаёт управление обратно.

## Слои персонажа

| Слой | Что делает | Чем считается |
|---|---|---|
| L0 Ходьба и намерение | шаг/бег под скорость клипа, разворот на месте, старт/стоп | Animator, CharacterController, кривые ускорения |
| L1 Поза под окружение | стопы на ступени, кисти к цели, взгляд, наклон, жесты | IK (Animation Rigging / свои задания) |
| L2 Отклик | добавки к суставам от ударов и контактов | **матрица масс в суставных координатах** (ниже) |
| L3 Перехват физикой | шатание с переносом веса, падение, подъём | 13 тел PhysX («тень»), смешивание видимой позы |
| L4 Равновесие | качнуться / подшагнуть / упасть | точка захвата (capture point), тензор инерции тела вокруг опоры |

## L2: отклик через матрицу масс (реализовано: `Scripts/Rig/React/ArticulatedResponse.cs`)

Координаты скоростей q̇ (dof = 6 + 3·12 = 42 для 13 частей):
корень — 3 сдвига + 3 поворота вокруг осей мира; каждый сустав — 3 поворота вокруг осей мира в точке сустава.

Якобиан точки p на части b (3×dof):
- сдвиг корня → единичная матрица E;
- поворот вокруг оси e в шарнире c на пути b→корень → `e × (p − c)`.

Матрица масс:

    M = Σᵢ [ mᵢ · Jv(comᵢ)ᵀ Jv(comᵢ)  +  Jωᵢᵀ · Iᵢ · Jωᵢ ],     Iᵢ = Rᵢ · diag(Iлок) · Rᵢᵀ

Удар импульсом J в точке p части b:

    Δq̇ = M⁻¹ · Jv(p)ᵀ · J            (Холецкий, 42×42 — микросекунды)

Эффективная обратная масса тела в точке p вдоль нормали n:

    w = nᵀ · Jv(p) · M⁻¹ · Jv(p)ᵀ · n

Проверено на числах: одно тело — точные Δv = J/m, Δω = I⁻¹(r×J);
цепь таз–бедро–голень — суммарный импульс тел = J;
w в голени ≈ 1/2.5 кг, в тазу ≈ 1/13.6 кг, всё тело 1/24 кг.

### Контакт с предметом без «кинематического тарана»

Тело — набор капсул по костям видимой позы. Для каждого касания с предметом (масса m_p, тензор I_p):

    vₙ = n·(v_предмета(p) − v_тела(p))
    λ  = −(1+e)·vₙ / (w_тела + w_предмета) + β·глубина/Δt,      w_предмета = 1/m_p + (r×n)ᵀ I_p⁻¹ (r×n)
    предмету — импульс λ·n,  телу — Δq̇ = M⁻¹ Jvᵀ (−λ·n)

Итог: бочка отскакивает с правильным импульсом, человек отклоняется по-настоящему;
удар в кисть отбрасывает руку, в грудь — качает всё тело; врезался в тяжёлый ящик — отшатнулся сам, ящик почти не двинулся.

### Возврат к анимации

Каждый сустав держит отклонение δθ (вектор поворота в осях родителя) и скорость δω:

    δω += Δq̇_сустава ;   δω̇ = −K·δθ − D·δω ;   δθ += δω·Δt

K, D — «тонус мышц» (сильнее у ног и спины, слабее у рук и головы; падают при оглушении).
Видимая поза: `кость = exp(δθ) · анимация` (от корня к концам).

### L4: равновесие — что делать с импульсом корня

Первые 6 компонент Δq̇ — скорость и вращение тела целиком.
Точка захвата: `ξ = x_ц.м. + v·√(h/g)`.
- ξ внутри стопы (≈12 см) → качнуться: тело как маятник вокруг опоры, `I_s φ̈ = m g h φ − K φ − D φ̇` (I_s — тензор инерции тела вокруг опоры, теорема Штейнера, `InertiaAbout`);
- ξ в пределах шага (≈0.9 м) → подшагнуть (L0 ведёт шаги к ξ — то, что нравится в v2 с бочками);
- дальше → L3: тень-тряпка с начальными скоростями из отклика, потом подъём анимацией со смешиванием.

### Опоры и тонус (реализовано, проверено на числах)

- **Стопы держат пол.** Якобиан опор J_c (скорость и угловая скорость стоп, 6 строк на стопу):
  `Δq̇ = (M⁻¹ − M⁻¹J_cᵀ(J_c M⁻¹ J_cᵀ)⁻¹ J_c M⁻¹) · Jvᵀ · J` — после удара скорость стоп ровно 0, гнутся колени и бёдра.
- **Тонус мышц прямо в матрице.** За время удара h мышцы держат суставы: `M' = M + diag(h·D + h²·K)` по суставам.
  Толчок в грудь 30 Н·с: обмяк (0) — позвоночник хлещет 10 рад/с, таз почти стоит;
  тонус (0.5–3) — тело принимает удар целиком: таз 0.4 м/с, голова 1.3 м/с, пружинят колени и бёдра.
  Одна ручка — от «спит» до «напряжён»; ею же играет язык тела (Bound/Free по Лабану).
- **Возврат.** Пружины по инерции `K = ω²M, D = 2ζωM` (Physics Control: f ≈ 2–4 Гц, ζ ≈ 0.5–0.8):
  отклик раскладывается на независимые затухающие колебания, удары складываются.

## Решения по итогам поиска (4 направления)

1. **Видна анимация, всегда.** Физическая тень (13 тел) — в режиме «ловит удары», видимый вес 0 (как PuppetMaster `Unmapped`).
   Вес физики поднимается по событию и затухает (всплеск w(t)); полный перехват — только падение/нокдаун.
2. **Animator в Normal**, гуманоидные клипы UAL, пороги смесей по замеренной скорости стопы (не 1.3, а 0.95 для шага).
   Кривые ускорения, разворот на месте, старт/стоп. Позже, если смесей мало — Motion Matching (MxM, MIT, работает с AnimationClip).
3. **IK — Animation Rigging 1.4.1** (официальный): стопы на ступени, кисти к цели, взгляд, наклон, Damped Transform для вторичного движения.
   Слой отклика — свой Burst-`AnimationScriptPlayable` в конце графа: `кость = Δq · анимация` до скиннинга.
4. **Контакт тела с предметами считаем сами** (кинематическое тело даёт бесконечную массу):
   капсулы по костям → проникновения → `λ` через эффективную массу (выше). Предмет получает честный импульс, человек — отклик.
5. **Равновесие — точка захвата** `ξ = x + ẋ/ω, ω = √(g/z₀)` (Euphoria `predictionTime` 0.2 с — то же):
   ξ в стопе → качнуться (голеностоп/бедро, аддитивно); снаружи → шаг в `ξ(T) = p + (ξ₀−p)·e^(ωT)`;
   не достать за 2–3 шага → падение (гистерезис между «шаг» и «падение»).
6. **Падение — активная тряпка** со скоростями из отклика; рефлексы Euphoria (ловить падение руками, махать руками, схватиться);
   подъём: поза лицом вверх/вниз, выравнивание корня, инерциализация перехода (Bollo, GDC 2018).
7. **Язык тела — каналы, общие для любого рига:** Height, Lean, TopPitch, TopRoll, Facing, Openness, ExtremityRaise, Breath, Tremor, Stepping.
   Усилия Лабана (время, вес, поток, пространство) → фильтр второго порядка `y + k1ẏ + k2ÿ = x + k3ẋ` (f, ζ, r) и тонус;
   настроение (возбуждение/знак/доминирование) — постоянные добавки. Жест = дорожки каналов + фазы (подготовка, удар, удержание, возврат).
   На человеке каналы → IK/добавки; на табурете → цели ног LegGait; на гибких → формы покоя.
8. **Гибкие живые предметы — XPBD с подшагами** (5–20) + **сопоставление формы кластерами** (Müller 2005): поза = смесь форм покоя,
   жёсткость кластера = тонус. Верёвка/хвост/позвоночник — стержни Коссера (Kugelstadt 2016) с анимируемым Ω⁰. Книга — две обложки + петля.
9. **Счёт — Burst + Mathematics** (уже в проекте, закрепить в manifest). **Rust DLL — не сейчас:** редактор Unity не выгружает
   нативные DLL (каждая пересборка = перезапуск Unity), а объём счёта мал (микросекунды). Математику держим в простых
   статических функциях — перенос в Rust возможен, если понадобится общий движок с внешними инструментами.
