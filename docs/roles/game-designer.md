# Геймдизайнер: вики роли (Metroidvany)

Здесь только законы, подтверждённые автором. Записывать коротко и с источником.

- Каждый добавленный элемент игрок использует. Их количество уравновешено. У элемента есть внутренний цикл, глобальное использование и интересное применение. Сюжетные предметы, головоломки и новых персонажей не придумывать: только то, что следует из функций пространств. (Автор через главного, 2026-11-13)
- Главное в локации — проходимость и замкнутость. (там же)
- Первая локация — крепость на окраине королевства, теперь тюрьма. Игрок начинает в тюрьме. (там же)
- Игра в полном 3D, вид от третьего лица; не 2.5D. Обход «по кольцу» — буквальный обход по стене. (Автор через главного, правка v2)
- Крепость каменная. (там же)
- Мелкие интерактивные объекты комнат решает геймдизайнер. Цитата: «это уже больше к мелким объектам интерактивным — они тоже нужны для комнат». (там же)
- Каким крепость быть не должна (претензии автора к v1): «маловат», трудно перемещаться, нет направленности, нет замкнутой инфраструктуры, «не жилое», скучно снаружи и внутри. (там же)

Предложения роли, которые ждут подтверждения автора: `design/gameplay_loops.md`.
