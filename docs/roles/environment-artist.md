# Художник по окружению — вики роли (Metroidvany)

Роль отвечает за уют и обжитость: предметы, свет, следы жизни, зелень, ориентиры.
Пишет `level/<loc>/dressing.txt` по формату `level/FORMAT.md` и доводит компилятор до 0 ошибок.
Раскладку стен не меняет. Если нужна правка карты — просит левел-дизайнера (или главного).

## Законы автора (подтверждены)
- Не хватает уюта — это задача роли окружения. (2026-11-14)
- Предметы стоят на полу или на опоре, висят на стене, помещаются на полке. Не накладываются и не висят в воздухе. (2026-11-14)
- Каждый предмет игрок использует. Количество уравновешено. Сюжетные предметы и головоломки не придумывать. Предмет объясняется функцией комнаты. (2026-11-13)
- Стиль: полумультяшный, не реализм и не лоу-поли. Только готовые ассеты; новые модели делаются в Blender только если ассета нет. (2026-11-13/14)
- Жилое — это состояния вещей: недоеденное, сохнущее, потёртое, подвинутое. Сумеречный свет: огонь, а между ним тень. (вики сценариста, v2)

## Приёмы
- Свет — главный инструмент уюта. Тёплые пятна у мест, где живут (очаг, стол, койки). Между ними тень, чтобы было видно, куда идти.
- Предметы ставятся группами вокруг функции: стол + лавка + миски, а не равномерно. Пустые полосы оставляются для прохода.
